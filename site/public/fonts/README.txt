Self-hosted Latin subsets of Geist (variable weights 300–700) and JetBrains Mono (400).
Source: https://cobaltlauncher.com/UIKit/fonts/ (same fonts used by the Cobalt website).
Both are licensed under SIL Open Font License 1.1; see OFL-Geist.txt and OFL-JetBrainsMono.txt.
The documentation theme uses these fonts; the npm package retains system font defaults.
